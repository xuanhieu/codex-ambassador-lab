Requirement-to-Test Trace Matrix
Ma trận yêu cầu → kiểm thử

Link requirements to evidence claims. Revision changes make evidence stale.
Liên kết yêu cầu với khai báo bằng chứng. Đổi phiên bản làm bằng chứng hết hiệu lực.

No tests execute here. “Pass” is a declared outcome, never proof of execution.
Không chạy kiểm thử tại đây. “Pass” là kết quả khai báo, không chứng minh đã chạy.

1. Import / Nhập dữ liệu

Requirements-only? Supply requirements; omitted tests and links become empty arrays. / Chỉ có yêu cầu? Mảng tests và links thiếu sẽ được tạo rỗng.

2. Add a deterministic test / Thêm kiểm thử xác định

Use a stable ID and describe the exact check. Run the real test separately before declaring an observed result.
Dùng ID ổn định, mô tả phép kiểm tra cụ thể. Chạy kiểm thử thật riêng trước khi khai báo kết quả quan sát.

Imported fixture claims stay synthetic. Changing this label does not execute or authenticate tests.
Đổi nhãn không chạy hay xác thực kiểm thử; dữ liệu mẫu vẫn là tổng hợp.

3. Link & inspect / Liên kết & xem xét

Changing an outcome preserves recorded revisions. “Attest current revisions” explicitly replaces them; use only after reviewing changed requirements and rerunning the check.
Đổi kết quả giữ phiên bản đã ghi. Chỉ xác nhận phiên bản hiện tại sau khi xem thay đổi và chạy lại kiểm thử.

4. Validate & export / Kiểm tra & xuất

Validate the exported file with python3 trace.py receipt.json. This CLI is the authoritative strict validator.
Kiểm tra tệp xuất bằng CLI trên; CLI là bộ kiểm tra nghiêm ngặt chính thức.
