# N074 Workshop Curriculum Planner
Local, no-API workshop planner. Choose learner segment (six profiles), objective (four topics), and time (20/45/90 minutes). Generates four phases, each with a real duration that sums exactly to the chosen total. Human checks and practice task are required.

Use the public URL /demos/workshop-curriculum-planner/, or open from a static server. Choose parameters and press Lập giáo án. Copy/export Markdown without transmitting the configuration.

This is an independent educational scheduling **simulation**: no calendar event, credentials, student records or sign-in. Run node --test tests/test_core.cjs. No OpenAI affiliation or qualification claim.
