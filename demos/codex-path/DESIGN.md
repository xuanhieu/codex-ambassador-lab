# Codex Path — Quiet Builder Design System
Date: 2026-10-25. Independent educational app; inspired by the restraint and task-first navigation of Codex, not a replica of an official product.

## Rules
- **Visual**: graphite/ivory with mint as a semantic cue only. No large cobalt/neon gradients, purple glow, rainbow or big decorative orbits.
- **Structure**: focused left navigation, task-first hero with small illustrative composer, simple workspace panels. First viewport prioritizes “start a task” and progress. Advanced depth appears on request.
- **Typography**: native system sans with humane, quiet hierarchy. Clear headings, compact metadata, generous line-height in lessons; respect browser zoom.
- **Components**: neutral cards, understated borders, guided input validation. Dark/light token pairs in codex-theme.css, loaded last.
- **Accessibility**: native buttons, links, forms, focus outlines, reduced-motion support, and no hover-only information. Test 390/768/1440px.
- **Honesty**: independently branded; no OpenAI logo, OpenAI Sans font files, or official endorsement. Preserve user-local progress privacy.
- **Technical**: preserve route IDs, starter.css, guide.css, JS state, Academy links and Cloudflare sanitization; run Quality Gate for every release.
- **References**: https://openai.com/index/introducing-the-codex-app/ ; https://openai.com/brand/ ; https://developers.openai.com/blog/designing-delightful-frontends-with-gpt-5-4.
