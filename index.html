01 · Flagship

Agent Ops Clinic

A local-first, bilingual lab for practising how to delegate software work to agents while keeping human approval, a decision trail and a spend cap.

  • MIT
  • 36 tests passing
  • Built with Codex CLI
  • VI / EN

20-minute workshop, 3 built-in exercises

  1. Make done observable. Write a concrete acceptance criterion, then hand the task to the Planner.
  2. Catch a risky handoff. See why release is disabled, record the risk decision, request changes.
  3. Make the budget say no. Set a $1 cap and watch release stay blocked until every gate passes.

An authored simulation, not a Codex integration or a multi-agent runtime.

03 · Supporting tools

Five tools, one problem each

All run offline in the browser on synthetic samples, with tests and a bilingual README.

  • Prompt Injection Clinic

    Problem Documents can hide instructions aimed at an agent.

    What it does Four simulated scenarios teach trust boundaries: sanitise, block or escalate to a human.

    35 tests passing

    Demo ↗Source ↗

  • Evidence Story Builder

    Problem Portfolios drift into claims nobody can verify.

    What it does Separates verified facts from claims, keeps an evidence ledger with provenance labels, exports Markdown/JSON locally.

    30 tests passing

    Demo ↗Source ↗

  • Workshop Accessibility Scorecard

    Problem Learners’ access needs get missed before a meetup.

    What it does Keyboard-first VI/EN checklist with a “Not sure” state, deterministic score and prioritised fixes; CSV/Markdown export. Not a WCAG certification.

    15 tests passing

    Demo ↗Source ↗

  • Approval Drill

    Problem When should an agent proceed, escalate or stop?

    What it does 12 synthetic agent tasks across 6 permission categories; choose Proceed / Escalate / Block and get a deterministic explanation.

    16 Node + 23 Python tests passing

    Demo ↗Source ↗

  • Screenshot Privacy Reviewer

    Problem Screenshots leak emails, keys and avatars.

    What it does Opaque masking with a review-confirmation gate before exporting a fresh PNG; no upload, no OCR.
